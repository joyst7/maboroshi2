## 0. スタンス

- 事実上「2」だが、実態は 1 作目の大型アップデート。設計思想はそのまま継承する。
- **1 作目本体には手を付けない。** 完成品として置いておく。2 は別物として作る。

### 継承する資産（壊してはいけないもの）

- 火力一辺倒にさせない設計（採掘速度・会心・運、どれにも投資価値がある）
- 運の要素
- 複数の攻略ルートが成立するバランス
- リザルト / ランク付け / 短時間クリアの緊張感
- 説明しすぎず、プレイヤーが体感で気づいていく作り
- B5 までを短時間で駆け抜ける、v1 の Simple な楽しさ（← これが大多数のプレイヤーの「本編」）

## 1. 背骨: 「運」

2 の変更はほぼ全部が「運」に接続する。バラバラの機能追加ではなく、**運を隠れた主軸にする**。

| 対象 | 状態 |
|---|---|
| ボスの表示時間 | 既存 |
| レア鉱石の出現率 | 強化 |
| 会心率の上乗せ | 強化（v5 で既に隠し効果あり） |
| 怪しい薬の倍率・効果時間の引き | 新規 |
| ボス撃破後の再出現確率の緩和 | 新規 |
| ネコのラッキーアイテム発生率 | 新規 |

狙い: プレイヤーが「あれ、運を上げた方がクリアタイム良くない…？」と**自力で解き明かす**。
火力ルートと張り合える裏ルートにする。ただし全部を運ステータス 1 本に委ねはしない。

## 2. やりたいこと（A: 演出・体験）

### A-1. 画面揺れの調整

- 症状: 採掘中の画面シェイクが強すぎ、掘り続けると常時グラグラで画面酔い
- 現状のコード: `self.shake` を `max()` でイベント時にセット（通常ヒット/会心=4, 鉱石破壊=5, 幻破壊=12）、
  毎フレーム -1 減衰、描画時に `pyxel.camera(rand)` でジッター。速掘り中に再セットが続いて実質連続揺れ
- 方針:
  - 揺れ幅を全体的に下げる
  - 減衰を速く（-2 or 乗算減衰、イージングアウト）
  - 通常ヒットでは揺らさない。会心と破壊だけに絞る案
  - 演出としての「手応え」は残す
- 数値はプレイして詰める。**独立作業なので最初に着手する**

### A-2. エンディングの実装（必須）

- 現状: クリアしても「実はここで終わりじゃない」的な投げっぱなしメッセージだけ。ED テーマ曲なし
- やりたい: しょぼくてもいいので「クリアした！」が伝わる演出 ＋ ED 音楽 ＋ ちゃんとした締め
- ストーリー: 彼女への指輪のために幻の鉱石 → **ED で指輪は完成する**
- 残す: リザルト表示、ランク付け、短時間クリアで真エンド
- **B10 まで行った場合の真エンド**で、v5 の「まだ先がある」という引きを回収する（源流の正体）

## 3. やりたいこと（B: 経済・攻略バランス）

### B-1. 強化薬 →「怪しい薬」に改名・ランダム化

- 現状の問題:
  - 5 倍 20 秒は強すぎ。最終ピッケルより安く、装備なしで最終ボス撃破可能
  - 階層で値上がり → 低層でまとめ買いする裏技が成立
- 改良:
  - 倍率 2〜5 倍のランダム、効果時間も長短ランダム
  - 名前を「怪しい薬」に。魔女の館らしい怪しさ
  - **運が高いほど良い倍率・長い時間を引きやすい**
  - 1 フロアの購入上限（3 個など）
  - 頼りきると「2 倍しか出ずボスに無駄撃ち」で自滅する諸刃の剣に
- まとめ買い裏技は**残す**（上限＋ランダムで自然に抑制）。数値はプレイしながら

### B-2. 低層ループの調整

- 現状: ボスは撃破後も再スポーンし破格のゴールドをくれる。クリアせず数体狩る→次の強武器即購入。
  薬ブースト併用で最速タイム。チート気味だが「味」でもある
- 改良:
  - ボスは一度撃破すると**再出現が 1/5 程度に激減**
  - 留まるロスが大きく、先へ進んで追加鉱石を数個砕く方がゴールド同等・EXP は明確に上
  - **運を上げると再出現が緩和** → 噛み合えば低層ループが最高効率、は "内緒" で残す
- 補足: 低層で運レベルを「ループ成立ライン」まで上げる金は正攻法だと足りない。
  その差を埋めるのが**ネコのラッキーアイテム**（「ラッキー！ネコが◯◯円みつけたよ！」）。
  → 基本は誰もやらない（進むのが正解）、いろいろ噛み合ったときだけ裏効率。「結局ネコ大事じゃん」の構造

### B-3. 運の全面強化

→ セクション 1 参照。B-1・B-2・レア鉱石・会心をすべて運に接続する

## 4. やりたいこと（C: 新規メカニクス / ボリューム）

### C-1. ボリューム = B6〜B10（やりこみ要素）

- 現状: 初回 30 分 → 慣れると 10〜15 分。「もっと掘りたかった」の声
- 失敗した試作の教訓: **「同じことの繰り返し＋数値インフレ」は完全につまらない**
- 解決: 階層を足すこと自体が答えではない。B6 以降は**質を変える**（下の「6 階以降」セクション）

### C-2. 邪魔する敵 / ゲームオーバー

- **入れる。** 目的は「画面を見てないとダメ」の担保
- ボス破壊チャレンジ中の 30 秒間、Z 連打しながら他作業…を許さない**軽い緊張感**。基本は緩め
- マップに邪魔する何かが出現 → 邪魔されると体力減 → 0 でゲームオーバー
- B1-B5 では軽いお邪魔。**B6 以降で本気の脅威になる**
- 未確定: 具体スペック（速度・ダメージ・湧き方・体力 0 で終了か階層戻しか・運との関係）
- C-3 とセットで設計する

### C-3. ペット: 掘削ネコ / ほりほりネコ

- プレイヤー追従。魔女の館で購入。**可能な限り可愛いドット絵ネコ**
- 位置づけ: 攻略に絡まなくてもいい、まったり勢の**目の保養枠**
- おまけで噛み合う役割:
  - C-2 の敵への**防御役**（追い払ってくれる → 快適に掘れる）
  - たまにラッキーアイテム（ゴールド発見）→ B-2 の金策に効く
- トレードオフ: ペットに金を使う＝基礎力・武器が遠のく。「ペット買う or スキルで避けて対応」をプレイヤーに委ねる
- B5 ランなら "可愛いだけ"、B10 ランなら "居ないと詰む" → ビルド分岐の一軸

## 5. 6 階以降の設計

失敗した試作の教訓は「同じことの繰り返し＋数値インフレ」。だから B6-10 は質を変える。

### 5.1 大方針: 経済を断ち切る

B1-B5 は「鉱石 → ゴールド → 火力」のループ。**B6 以降、魔女の店は無い**
（魔女は B5 で「最果てだ」と言って付いてこない）。

これだけで狙いの分岐が自動的に成立する:

- **溜め込んだゴールドが死ぬ。** 「あと 1 回で次のピッケル」の貯金が、B6 に入った瞬間ただの重り
- **B6 以降で価値を生み続けるのは、既に振ったステータスだけ** — 運（無料でレア湧き）、
  会心率＋会心ダメージ倍率（無料で火力倍化）、移動（回避）、防御。純火力ピッケル型は "次の武器" が無くて頭打ち
- B5 を A ランクで抜けた瞬間、「しまった、会心と運に振っておけば」となる。
  **この後悔がドラクエ 6 / シレンの「どっちがいいねん！」の気持ちよさ**

### 5.2 B5 の位置づけ（重要）

- **B5 クリア＝大多数にとっての「本編」。負け犬でも途中でやめたでもない。** v1 の Simple な楽しさそのもの
- B5 ランの真骨頂 = **最速タイム狙い**。強い腕力・強い武器で速攻、最後は運も絡めて怪しい薬で突破
- 短時間クリアの真エンド / ご褒美は B5 の中でしっかり設計する
- B6 以降は「おすすめしない」枠。**そっちを本編扱いしない。** 「なんやねん、この先もあるんかい？」で突っ込む対象
- B6 以降の入口は控えめに提示する（B5 プレイヤーが「コンテンツを取り逃した」と感じないように）

### 5.3 ランクと入場ゲート

- **ランクはタイム基準（S / A / B / C …）。** 速度こそ B5 の正義。ここはブレさせない
- **B6 への はしごは A ランク以上のクリアで開く**（同一ラン、後戻り不可 or 戻ると深層挑戦は放棄）
- 意図的な friction（＝良い意味での「いやがらせ」）:
  - 純速度ビルド → S/A は楽勝、でも B6 で会心倍率・運が無くて詰む
  - 深層ビルド（運・会心）→ B5 タイムが落ちて A ランクに届かず、その周は B6 に入れない
  - **両立には習熟が要る。** 慣れれば「B10 攻略を見越したビルドで、なお B5 A ランク」が可能
  - この A 評価ラインの調整が 2 の最難関でありやりがい

### 5.4 各階のツイスト（骨子案・要検討）

各階 "1 つだけ" 質的な変化。同じことの繰り返しにせず、かつ作りすぎない。

| 階 | ツイスト | 効くステータス |
|---|---|---|
| B6 | 店なしショック。ゴールドが無価値だと体で分かる階。邪魔する敵が本気を出し始める | 防御・ペット |
| B7 | 視界が狭い（暗い）。はしごを開けるには鉱石から「幻片」ドロップが要る＝運ゲー | 運・移動 |
| B8 | 崩落。階全体に制限時間、居座るほど邪魔が増える。掘るスループット勝負 | 会心・採掘速度 |
| B9 | 邪魔の群れ。掘る手を止めさせてくる。捌けないと体力が溶ける | 防御・ペット・移動 |
| B10 | 源流。幻の鉱床の "本体"。ちょっとした戦闘シーケンス → **真エンド** | 総合力 |

### 5.5 エンディング構造

1. B5 クリア → **通常エンド**（指輪は完成する）。リザルト・ランク・タイム
2. B5 を A ランク以上 → 「降りる / ここで終える」の選択（控えめに提示）
3. B10 クリア → **真エンド**（源流の正体。v5 の投げっぱなしを回収）
4. S ランク / 真エンドのタイム閾値は新バランス確定後に**逆算して決める**

### 5.6 設計の芯（6 階以降で絶対ブラさない）

**ゲームはどっちの目標でプレイしてるか教えない。**
正解の買い物は、自分がどこまで潜ると決めたかで後から変わる。
しかも潜る決断（B5 A ランク時点）は、金の大半を使い切った後に来る。
この「引き返せない後悔」が面白さ。

## 6. 「8 分」についての注記

- 8 分は **v1 のバランスでの結果**であって、守るべき定数ではない
- 設計目標は「**人間のプレイスキルの限界近く**」というタイム感。数字は 9 分でも 11 分でもよい
- Claude が中間バージョンをテストして「N 分でクリア＝かなり上手い」と判断したら、
  まず N 分を真エンド / S ランク基準に置いて、人間テストで詰めながら動かす
- **どの数値も定数扱いしない。バランスが先、閾値は後**
