### 作り方の原則（コウモリの件で確立）

**手触りは検算では出てこない。** コウモリはシミュレーション上「4分で4回被弾、妥当」だったが、
実際に触ると「避け続けるのがうざい」という別の欠陥があった。数字は測れるが手触りは測れない。

したがって:

- **1機能1コミット。** 手触りがハズレたら `git revert` 一発で戻せるようにしておく
- 新しい"動詞"を増やす変更（＝プレイヤーの行動が変わるもの）は、必ず実機テストを挟んでから次へ進む
- 定数1個で直せる変更（乱数の範囲、確率、価格）は先にまとめて作ってよい
- **手触りが計算で出せないと分かったら、選択肢を実機で切り替えられるようにして人に選ばせる。**
  コウモリの強さはシミュレーションを2通り書いて2回とも外した。1〜5キーで即切り替えできる
  ようにしたら一度のプレイで決まった

### 同じ数字が、層ごとに別の意味を持つ

コウモリを最強設定にできた理由。上手い人には「脳死で掘るな、1フロア3回被弾は駄目」という
緩い条件にしかならないが、矢印キーに不慣れな人（子どもなど）には本物の脅威になり、
体力ゼロで戻されて再挑戦する、という深い遊びが成立する。

HP0 の罰を B1-B5 と B6-B10 で非対称にしたのと同じ構造。
**一つの設定が、プレイヤーの技量に応じて別のゲームとして機能する**なら、攻めた側に倒してよい。

## 2. やりたいこと（A: 演出・体験）

### A-1. 画面揺れの調整 ✅ 実装済み

- 症状: 採掘中の画面シェイクが強すぎ、掘り続けると常時グラグラで画面酔い
- 原因は 2 つ:
  1. 毎フレーム乱数で `pyxel.camera` をずらしていた（＝白色ノイズ。これが酔いの正体）
  2. 通常ヒットと会心でも揺れを再セットしていた。会心率は最大 65% なので実質**揺れっぱなし**
- 対処:
  - 当たった向きへ一度弾いて、振幅を減らしながら往復させる形に変更
  - **通常ヒットと会心では揺らさない。** 手応えは粒子・効果音・ポップアップが既に出している
  - 鉱石破壊 5 → 1.6 / 幻破壊 12 → 4.0
- つまみ: `SHAKE_BREAK` / `SHAKE_PHANTOM` / `SHAKE_HIT` / `SHAKE_DECAY`

### A-2. エンディングの実装（必須）

- 現状: クリアしても「実はここで終わりじゃない」的な投げっぱなしメッセージだけ。ED テーマ曲なし
- やりたい: しょぼくてもいいので「クリアした！」が伝わる演出 ＋ ED 音楽 ＋ ちゃんとした締め

## 3. やりたいこと（B: 経済・攻略バランス）

### B-1. 強化薬 →「怪しい薬」 ✅ 実装済み（未プレイ確認）

- 旧仕様の問題: 5 倍 20 秒は強すぎ。最終ピッケルより安いのに装備なしで最終ボスを倒せる
- **倍率の基準**: バイキルトが 2 倍であることを思えば、5 倍も 4 倍も狂った数字。
  そこで **1.5 / 2.0 / 2.5 / 3.0 の 4 段階**に刻んだ
- 効き目の長さも 10〜22 秒でランダム。飲むまで分からない
- 1 フロアの購入上限 3 本。買い切ると「この階ではもう売ってくれない」
- ショップの説明は「飲むまで効き目はわからない」だけ。範囲は教えない
- 何が出たかは言葉で返す:
  x3.0「身体が燃えるようだ！」/ x2.5「力がみなぎる！」/ x2.0「効いてきた」/ x1.5「……気のせいか？」

#### 引きの分布

| | x1.5（ハズレ） | x2.0 | x2.5 | x3.0 |
|---|---|---|---|---|
| 運 Lv0 | **46.5%** | 31.4% | 16.9% | 5.2% |
| 運 Lv16 | **13.5%** | 29.3% | 35.5% | **21.8%** |

威力（倍率 × 秒）は旧比で運 0 が 0.30 倍、運 16 でも 0.41 倍。大幅な弱体。
ただし**効くのは平均値ではなく「肝心なときに外す確率」**。それが 46% から 13% に下がる。
これが運の本当の価値で、数字を見せずに体で分からせる部分。

#### つまみ

`POTION_TIERS` / `POTION_SEC_MIN` / `POTION_SEC_MAX` / `POTION_LUCK_SEC` / `POTION_PER_FLOOR`

### B-2. 低層ループの調整 ✅ 実装済み（未プレイ確認）

旧仕様の実測: **B4F のボス周回は毎分 240 万ゴールド。通常採掘の約 30 倍。**
（同額を掘って稼ぐには宝石鉱脈を毎分 1095 個。実際は多くて 30 個程度）

#### 効かなかった案と、その理由

設計メモの当初案は「再出現確率を 1/5 に」だった。**これは効かない。**
周期 40 秒のうち 18 秒が撃破後クールタイムで、確率を 1/5 にしても周期は 47 秒にしかならない。
**周期の大半を占めるのはクールタイムであって、抽選ではない。**

さらに、確率・待ち・報酬をどれだけ絞っても、**無限に回せる蛇口である限り破綻する**。
運で緩和すると倍率が戻ってしまい、運 16 で最終ピッケルを 1.5 分で買えてしまった。

#### 採用した形: 狩るほど取り分が減らす

| | 撃破済みの階での値 |
|---|---|
| クールタイム | 45 秒（運 1 につき -1.4 秒） |
| 出現率 | 10%（運 1 につき +1.2%） |
| 2 体目の報酬 | 12%（運 1 につき +2.2%） |
| 3 体目以降 | さらに **0.55 倍ずつ減衰** |

減衰があるため、居座って得られる合計は頭打ちになる。**蛇口が有限になった。**

#### B4F に居座って 8 体狩った場合

| 運 | 取り分の推移 | 8 体の合計 | 同時間の採掘比 |
|---|---|---|---|
| 0 | 192k → 105k → 58k → 31k → 17k | 423,094 | **2.6 倍** |
| 8 | 776k → 427k → 234k → 129k → 71k | 1,711,556 | 8.0 倍 |
| 16 | 1721k → 947k → 520k → 286k → 157k | 3,794,307 | **16.2 倍** |

- **運 0 では 40 体狩っても 42 万で頭打ち。最終ピッケル（350 万）に永久に届かない**＝金策として成立しない
- **運 16 なら 6 分で 379 万**＝最終ピッケルが買える。狙い通り「運を極めた者だけ裏ルートが正攻法を超える」
- 減衰により **「1〜2 体だけ追加で狩って先へ進む」が最適**になる。3 体目から急に枯れるので居座る理由が消える
- 裏技の味は残しつつ、青天井は塞いだ

#### つまみ

`PHANTOM_RESPAWN_CHANCE` / `PHANTOM_RESPAWN_LUCK` / `PHANTOM_RESPAWN_COOLDOWN` /
`PHANTOM_RESPAWN_LUCK_COOL` / `PHANTOM_REPEAT_REWARD` / `PHANTOM_REPEAT_LUCK` / `PHANTOM_REPEAT_DECAY`

### C-2. 邪魔する敵 / ゲームオーバー ✅ 第1段 実装済み

**罰の本体は HP ではなくコンボ。** `COMBO_TIMEOUT = 20`（0.67 秒）なので、
一度どかされた時点で最大 2 倍のコンボ倍率が確定で飛ぶ。
最適化している速攻勢ほど痛く、まったり勢はほぼ無痛。UI で煽らなくていい。

正体: 坑道のコウモリ（B6+ は幻の影。同じコードでパラメータ違い）。

```
① 予告   盤面のふちに赤いマーカーが点滅（既定 0.6〜0.8 秒）
② 接近   プレイヤーへ寄る。最高速は基礎移動より遅い＝逃げ切れる
         加速を鈍く（PEST_ACCEL）してあるので引きつけて横に抜ければ通り過ぎる
③ 接触   ノックバック / 採掘中断 / コンボ全損 / HP -1 / 無敵 1 秒
④ 事後   B1-B5: 一度当てたら去る    B6+: 居座って何度も来る（linger フラグ）
```

**鉱石は壊さない。金も盗まない。仕事は「1 秒どかす」ことだけ。**

#### HP とゲームオーバー（非対称）

**HP 3。階層を降りるたび全回復。** 尽きるのは「同じ階で 3 回やられた」ときだけ。

| 区間 | HP 0 のとき |
|---|---|
| B1〜B5 | **1 階層戻される。** 装備・金・強化は全部維持。純粋なタイムロス |
| B6〜B10 | **ゲームオーバー**（未実装）。ただし B5 の通常エンドとランクは確定済みなので周回の成果は残る |

速攻勢には「S ランクが消える」＝事実上のゲームオーバー、まったり勢には「うわー」で済む。
**同じルールなのにプレイヤー層ごとに意味が変わる。**

#### 運の効き方（説明しない）

- 出現間隔が伸びる（運 1 につき +5%）
- 予告時間が伸びる（運 1 につき +0.7 フレーム）

#### 防御ステータスは追加しない

対処法は既に 3 つある: **自分の操作 / あしの速さ（既存）/ ネコ**。
ここに防御を足すとネコと役割が丸かぶりして薄まる。
むしろ一番地味だった**「あしの速さ」が回避ステータスに化けた**のが収穫。
新ステータス 0 個で既存 2 つ（移動・運）が深くなった。

#### 主な調整つまみ

- `FLOORS[n]["pest"]` の `every`（出現間隔・秒）／ `speed` ／ `warn`（予告フレーム）／ `linger`
- `PEST_ACCEL`（低いほど避けやすい）／ `PEST_MAX` ／ `PLAYER_MAX_HP`
- 現状 B1=14 秒 → B5=8 秒間隔。ボス戦 30 秒中に 2〜3 回来る計算。**要プレイ検証**

### C-3. ほりほりネコ ✅ 実装済み・プレイ確認済み

- プレイヤー追従。魔女の館で購入。ドット絵 3 枚（座り / まばたき / 飛びかかり）+ 揺れるしっぽ、左右反転あり
- 位置づけ: 攻略に絡まなくてもいい、まったり勢の**目の保養枠**。本体はそこ
- おまけで噛み合う役割:
  - 邪魔者が近づくと飛びかかって追い払う（クールタイム 5 秒。**群れは捌けない**）
  - たまに落とし物を見つける → B-2 の金策に効く
- 掘りは手伝わない

#### 値段 30,000 の意図

金のピッケル（45,000）を買うのが一段遅れる痛みを狙った額。
**速攻ビルドには割に合わず、運ビルドには落とし物ですぐ元が取れる。**
つまりネコを買うかどうか自体が、どちらを目指すかの表明になる。

#### 落とし物の実測（1 分あたり・8 回試行の平均）

| | 運 0 | 運 16 | 倍率 |
|---|---|---|---|
| B3F | 9,015 | **39,680** | 4.4 倍 |
| B5F | 65,931 | **325,166** | 4.9 倍 |

運が「見つける確率」と「見つける額（`gold_mult`）」の両方に効くので二乗で伸びる。
狙い通り、低層で運を伸ばすための金策として機能する。

#### プレイ確認の結果（2026-09-04）

- **可愛さは合格。** 細部（しっぽの揺れ・まばたき）は 8 ドットでは伝わらないが、それでいい
- 30,000 は「初見ならまずスルーする」額。効果が分からないのでピッケルや火力を優先する。
  **これは狙い通り。** 一周してから「次はネコを試すか」となる位置づけ
- **邪魔者をほぼ 100% 追い払うのは、そのままで良いと判断。**
  「そのために 3 万払ったんだから」。快適さを金で買う選択肢として成立している
- 落とし物は「うるさくない、むしろ物足りない」＝おまけとして適正
- 追従距離はもう少し近くてもよい（問題ではない）
- 保留アイデア: 16 ドットの大きなロボネコ。簡単にできるなら試す程度

## 5. 6 階以降の設計

失敗した試作の教訓は「同じことの繰り返し＋数値インフレ」。だから B6-10 は質を変える。

### 5.1 大方針: 経済を断ち切る

B1-B5 は「鉱石 → ゴールド → 火力」のループ。**B6 以降、魔女の店は無い**
（魔女は B5 で「最果てだ」と言って付いてこない）。

これだけで狙いの分岐が自動的に成立する:

- **溜め込んだゴールドが死ぬ。** 「あと 1 回で次のピッケル」の貯金が、B6 に入った瞬間ただの重り
- **B6 以降で価値を生み続けるのは、既に振ったステータスだけ** — 運（無料でレア湧き）、
  会心率＋会心ダメージ倍率（無料で火力倍化）、移動（回避）、防御。純火力ピッケル型は "次の武器" が無くて頭打ち
- B5 を A ランクで抜けた瞬間、「しまった、会心と運に振っておけば」となる。
  **この後悔がドラクエ 6 / シレンの「どっちがいいねん！」の気持ちよさ**

### 5.2 B5 の位置づけ（重要）

- **B5 クリア＝大多数にとっての「本編」。負け犬でも途中でやめたでもない。** v1 の Simple な楽しさそのもの
- B5 ランの真骨頂 = **最速タイム狙い**。強い腕力・強い武器で速攻、最後は運も絡めて怪しい薬で突破
- 短時間クリアの真エンド / ご褒美は B5 の中でしっかり設計する
- B6 以降は「おすすめしない」枠。**そっちを本編扱いしない。** 「なんやねん、この先もあるんかい？」で突っ込む対象
- B6 以降の入口は控えめに提示する（B5 プレイヤーが「コンテンツを取り逃した」と感じないように）

### 5.3 ランクと入場ゲート

- **ランクはタイム基準（S / A / B / C …）。** 速度こそ B5 の正義。ここはブレさせない
- **B6 への はしごは A ランク以上のクリアで開く**（同一ラン、後戻り不可 or 戻ると深層挑戦は放棄）
- 意図的な friction（＝良い意味での「いやがらせ」）:
  - 純速度ビルド → S/A は楽勝、でも B6 で会心倍率・運が無くて詰む
  - 深層ビルド（運・会心）→ B5 タイムが落ちて A ランクに届かず、その周は B6 に入れない
  - **両立には習熟が要る。** 慣れれば「B10 攻略を見越したビルドで、なお B5 A ランク」が可能
  - この A 評価ラインの調整が 2 の最難関でありやりがい

### 5.4 各階のツイスト（骨子案・要検討）

各階 "1 つだけ" 質的な変化。同じことの繰り返しにせず、かつ作りすぎない。

| 階 | ツイスト | 効くステータス |
|---|---|---|
| B6 | 店なしショック。ゴールドが無価値だと体で分かる階。邪魔する敵が本気を出し始める | 防御・ペット |
| B7 | 視界が狭い（暗い）。はしごを開けるには鉱石から「幻片」ドロップが要る＝運ゲー | 運・移動 |
| B8 | 崩落。階全体に制限時間、居座るほど邪魔が増える。掘るスループット勝負 | 会心・採掘速度 |
